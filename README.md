# Ephraitech Company Website (Version 2)

The company website of **Ephraitech Unified Solutions**, an ICT company in Uganda offering custom software development, cloud infrastructure, networking, hardware servicing, and IT consulting.

**Live site:** https://ephraitech.com

## About this project

Version 2 of the website is built on CodeIgniter 4. The original site was written in core PHP, and the entire codebase was converted to the CodeIgniter framework for this version. The site is hosted and running live.

**My work on this project**
- Converted the entire core PHP codebase to the CodeIgniter 4 framework
- Created the database and its tables

## What the live site includes

- Home, About, Services, and Contact pages
- Portfolio of the company's software projects
- Request a Quote page

## Built with

PHP, CodeIgniter 4, MySQL, HTML, CSS, JavaScript

## Getting started

1. Clone the repository.
2. Install dependencies with `composer install`.
3. Copy `env` to `.env` and set your base URL and database details. Never commit your `.env` file.
4. Create a MySQL database. Import the SQL file if the repository includes one, or run `php spark migrate` if it uses migrations.
5. Start the app with XAMPP, or run `php spark serve`.
